# Cinema Village 🎬

Site permettant aux clients du cinéma de consulter les films à l'affiche (données de l'API OMDb).

## Dépôt GitHub

https://github.com/karltchoumba/mini-projet-cinema

## Pages

- `index.html` : films tendances et films de 2024
- `search.html` : recherche de films en temps réel
- `movie.html` : détail d'un film

## Lancer le projet

1. `npm install`
2. Créer un fichier `.env` à la racine contenant : `VITE_OMDB_API_KEY=La_cle` (la clé est fournie dans le fichier .env du rendu Moodle)
3. `npm start`
4. Ouvrir http://localhost:5173

## Organisation Git

- `main` : version finale
- `develop` : intégration du travail
- `feature/*`, `chore/*`, `docs/*` : une branche par tâche
